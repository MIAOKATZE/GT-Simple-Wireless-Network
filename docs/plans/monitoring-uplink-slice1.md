# 监测与上行整合 第一批实现说明

本批是整合路线的首个兼容闭环，不代表 MonitorProfile 持久档案、离线作业、Web、全局字节预算或全部增量协议已经实现。

## 变更范围

### 便携监测的来源一致快照复用

- 保持协议 60 的字段布局和 packet discriminator，不无协商改变旧客户端语义。
- 新客户端仅对普通只读请求声明曲线复用能力。线上的负 knownRenderVersion 是非负逻辑版本的按位取反；旧服务器因版本不匹配而返回完整数据。
- 新服务器仅在明确选择复用且完整版本一致时省略四组曲线。响应负 renderVersion 表示已确认版本的曲线不变；版本零不能标识可复用响应。
- 客户端要求终端、来源 UUID、维度坐标、chartKey、请求序号和完整版本均相符，才能从已保存快照恢复。丢失基线时重新请求完整只读快照，不把不完整响应当作新鲜数据。
- 变更操作始终返回完整快照，操作确认不依赖曲线重建成功；恢复查询不能重发已经完成的变更操作。
- 识别旧服务器的同版本完整响应后，本连接恢复正版本请求，避免长期重复发送完整 render；新连接重新识别。
- 服务端比较有界原始历史、真实时间戳及完整配置，不再只依赖哈希、首尾或另一个窗口的最新点。配置、数组和列表在发布边界复制。
- live EU 与 AE 连通状态仍随响应更新，不因曲线复用而冻结。

复用仅针对选中的 ready detail；pin-only 图表仍使用既有路径。完整历史变化时仍传完整有界曲线，本批不是原始历史游标协议，也没有配置/历史版本的完全分拆。

### 服务端监测生命周期

- 无线 EU 调度器区分服务器/世界实例，并检测观察到的世界 tick 回退，避免跨会话沿用旧的采样节奏。
- 数据集的去重锁与统计连续性同时处理回退；同一 tick 已采样时不重新打开锁，非活跃数据集也保留连续性失效标记而不会被自动激活。
- 新的可选 NBT 布尔字段 sampleClockReset 保存待处理的连续性边界，旧存档缺少该字段仍可读取。它不改变所有权或访问权限。
- 回退后的首个无法可靠计算的速率沿用零初始速率约定，而非声称该区间实际没有能量变化。相同数值 tick 与 API 先采样的歧义场景可能保守地多置零一个间隔；保留原始余额和历史，之后恢复正常差分。
- 尚无真实请求、已过期或落在未来 tick 的临时请求不自动变活跃，必须由真实观察重新登记。
- DIT 持有人周期核对及登录同时考虑主背包和可选 Baubles 栏，按既有终端 UUID 去重并保留 holder refcount。自动放置绑定仍沿用原规则，不扩张游戏权限。

## 与后续模型的接口

本批使用现有物理面板来源与终端/会话身份作为 legacy adapter。未来持久档案 ID 不复用面板 UUID 字段；SourceKey、ProfileId 和订阅字段范围须在对应功能切片中接入真实使用者。协议 60 的曲线复用只是一项有限能力，不承载未来任意字段差量。

后续历史游标必须基于完整确认版本，并处理删除、窗口变化、来源代际、失效及全量恢复。归一化曲线不能直接追加旧归一化点，因为新极值可能改变整个窗口的比例。

## 验证记录

- `compileJava compileTestJava test assemble`：通过，Jabel 初始化成功。
- 完整测试：254 个测试类、1,340 项，1,337 项执行通过、3 项显式 opt-in 压力基准跳过；本批新增 33 项全部通过。
- 跳过项：QuantumSecurityStressBenchmarkTest、QuantumRegistryStressBenchmarkTest、QuantumStatsAliasStressBenchmarkTest，需要测试 JVM 显式开启 `gtswn.stress=true`，本轮未启用。
- 运行用 reobf JAR 内 872 个 class 均为 major 52（Java 8），无多版本 class 目录。
- 格式检查：完整 `spotlessCheck` 通过；只对本批 8 个 Java 文件应用仓库固定版本的格式器，无无关源码变更。
- 本批未执行专用服务端或客户端启动，也未进入存档或开展实服负载验证。

验证环境采用独立 Gradle 9.3.1、Corretto 25 启动 Gradle、Corretto 17 编译现代语法至 Java 8，以及编译 JVM 启动时加载 ByteBuddy agent 1.14.9；Core 依赖沿用仓库声明的 0.1.21。环境适配未修改仓库构建配置。

四组各 61 点的受测 unchanged 响应比旧响应少 1,952 字节。这个单元测试差值只表示应用包体，不代表网卡流量或实服 MSPT 改善；冷启动、历史变化、pin-only、旧服务器等情形不适用这一差值。

## 回退与兼容

- 旧客户端继续正版本请求并收到原有曲线格式；新客户端在旧服务器上有完整响应回退与连接级能力识别。
- 此批不迁移或删除现有终端绑定、历史、所有权及存储格式主体。
- 若撤回本批代码，旧读取器忽略新增的可选 NBT 标志；需要保留回退边界语义时应维持新版或从备份恢复验证，不把降级视为等价的时钟恢复保证。
- 发布仍由维护者审核 PR 后决定，不自动合并、改版本号、打 tag 或发布构件。
